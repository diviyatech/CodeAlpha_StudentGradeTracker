# Student Grade Tracker

## Description
Student Grade Tracker is a Java-based application developed to manage and analyze student grades. The program allows users to enter student marks, calculate the average score, identify the highest and lowest marks, and generate a summary report.

## Features
- Store student grades
- Calculate average marks
- Find highest mark
- Find lowest mark
- Display summary report
- Simple console-based interface

## Technologies Used
- Java
- Arrays / ArrayList
- Scanner Class
- Object-Oriented Programming (OOP)

## How to Run
1. Open the project in any Java IDE.
2. Compile the Java program.
3. Run the program.
4. Enter student marks when prompted.
5. View the generated report.

## Sample Output
- Average Marks
- Highest Marks
- Lowest Marks
- Student Grade Summary

## Learning Outcomes
- Understanding of Java fundamentals
- Working with Arrays and ArrayLists
- User input handling using Scanner
- Basic data analysis and reporting
